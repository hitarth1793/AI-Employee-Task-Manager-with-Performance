# Employee Performance & Review

Admin-only module that calculates an employee's performance category from actual application records.

## Categories
- Excellent: 90% or above
- Good: 75% to 89.99%
- Average: 50% to 74.99%
- Poor: below 50%

## Calculation
- Task completion: 35%
- On-time delivery: 30%
- Attendance: 25%
- Leave discipline: 10%

Approved leave is not penalized. Absences recorded without an approved leave request affect leave discipline.

The Admin can save a review for a selected period with an optional comment. Each saved review keeps a snapshot of the calculated result for performance history.
