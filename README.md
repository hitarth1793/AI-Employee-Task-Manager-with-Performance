# AI-Powered Employee Task Management & Virtual Assistant

A Django-based employee/manager/admin task management system based on the supplied project architecture.

## Included modules
- Authentication & role management
- Separate Manager and Employee dashboards
- Employee management
- Task management
- Priority, deadlines, status, comments and history
- Scrum/Kanban board with drag-and-drop
- Sprint management
- Notifications
- Rule-based AI virtual assistant (no API key required)
- Reports and CSV export
- Calendar
- Team communication
- Leave & attendance
- Admin Employee Performance & Review (Poor / Average / Good / Excellent) based on task delays, on-time delivery, attendance and leave discipline

## AI assistant providers
Choose **Auto** in the assistant to try configured providers in this order: Gemini, GroqCloud, Ollama. You can also select a provider directly or choose built-in local checks. Auto fallback may send the prompt and attached code to another configured provider.

```powershell
# Optional Gemini provider
$env:GEMINI_API_KEY = "your-gemini-api-key"
$env:GEMINI_MODEL = "gemini-3.6-flash"

# Optional GroqCloud provider (hosted; needs a Groq API key)
$env:GROQ_API_KEY = "your-groq-api-key"
$env:GROQ_MODEL = "openai/gpt-oss-20b"

# Optional Ollama provider (local; no provider API key)
$env:OLLAMA_BASE_URL = "http://localhost:11434/v1"
$env:OLLAMA_MODEL = "qwen2.5-coder:7b"

python manage.py runserver
```

For GroqCloud, create an API key from [Groq Console](https://console.groq.com/keys). Groq may offer free-tier usage subject to account eligibility and rate limits; check its current [rate limits](https://console.groq.com/docs/rate-limits). The OpenAI ChatGPT website's free plan does not include a free API key; API access is separately billed.

For Ollama, install it from [ollama.com/download](https://ollama.com/download), then run `ollama pull qwen2.5-coder:7b` in PowerShell. Ollama serves the model over a local HTTP API and requires no cloud provider key. The model download uses disk space; inference uses your computer's memory and processor.

The assistant supports account-specific saved chats (including delete and text export), copying answers/code, stopping or retrying a response, and checking configured provider/model availability. Code-review prompts request severity-ranked findings. Choose a response language in the assistant. Task details are excluded by default; enabling **Include my active task details** explicitly sends up to eight of the signed-in user's active task titles, statuses, priorities, deadlines, and project names to the selected provider. Auto fallback can send that information to a cloud provider. Saved conversation data is stored in the application's database and is visible only to its owner.

## Windows setup

```powershell
cd AI_Employee_Task_Manager
py -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python manage.py makemigrations
python manage.py migrate
python manage.py seed_demo
python manage.py runserver
```

Open:
http://127.0.0.1:8000/

## Demo accounts

For local development only, `seed_demo` creates predictable demo accounts. Do not run it on a public deployment; the command refuses to run when `DEBUG=False`.

## Important
The database is SQLite and is created by migrations. If you ever remove `db.sqlite3`, simply run:

```powershell
python manage.py migrate
python manage.py seed_demo
```

## Render demo deployment

This repository includes a Render Blueprint in `render.yaml`. In Render, create a **Blueprint Instance**, connect this public GitHub repository, and apply the Blueprint. Render will install the requirements, collect static files, run migrations, and start Gunicorn. `DJANGO_SECRET_KEY` is generated by Render; the application runs with `DEBUG=False`.

This Blueprint intentionally uses Render's free web-service plan and the default SQLite database for a temporary demo only. Free services have an ephemeral filesystem, so database changes (including user accounts) can be lost when the service restarts, spins down, or redeploys. Do not enter real employee, attendance, or performance data. For production, use a persistent managed database and paid hosting, then back up and migrate any demo data appropriately.
